This guide explains where to find Destination Earth data and how to try one small, reproducible example. Read the service pages without an account. Create an account only for the live route you choose.

## A quick reading path

1. Read the [ecosystem overview](ecosystem/README.md) to distinguish the Platform, Data Lake, Digital Twins, and related external services.
2. Use the [service directory](services/README.md) to match a task to a data or computing service.
3. Check that service's account and permission requirements in the [access guide](setup/accounts.md).
