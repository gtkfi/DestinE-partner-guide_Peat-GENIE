# Choose a service

[Home](../../README.md) · [Access](../setup/accounts.md) · [Tutorials](../../notebooks/README.md)

Choose the data or task you need. Open one service page for its access route and a matching notebook, if available.

| Need | Route | Example in this repository |
| --- | --- | --- |
| Find data in a browser | [EDEN](eden.md) or [SesamEO](sesameo.md) | [EDEN precipitation](../../notebooks/10-eden-precipitation.ipynb) or [SesamEO imagery](../../notebooks/02-sesameo-ndvi.ipynb) from downloaded files |
| Explore a map and export imagery | [NUPSI](nupsi.md) | [Inspect an export](../../notebooks/03-nupsi-raster-inspection.ipynb) |
| Search and obtain Data Lake products | [HDA](data-lake-hda.md) | [Landsat discovery](../../notebooks/13-hda-landsat.ipynb) |
| Work with climate or terrain arrays | [Earth Data Hub](earth-data-hub.md) | [ERA5-Land](../../notebooks/09-edh-era5-land.ipynb) or [DEM](../../notebooks/11-edh-dem.ipynb) |
| Explore a Digital Twin simulation | [Polytope](polytope.md) | [Climate DT subset](../../notebooks/12-polytope-climate-dt.ipynb) |
| Search or process Sentinel images | [CDSE Browser / Sentinel Hub](cdse-sentinel-hub.md) | [Sentinel-2 Process API](../../notebooks/04-sentinel-2-process.ipynb), plus other [Sentinel tutorials](../../notebooks/README.md) |

For hosted code or larger workflows, see [Insula](insula.md), [Data Lake computing and MLOps Studio](near-data-computing.md), [DeltaTwin](deltatwin.md), and [EO4EU](eo4eu.md). These are optional service notes; this repository has not run jobs on them.

**Accounts differ.** CDSE has its own registration and OAuth client. Earth Data Hub uses an EDH key. HDA and Polytope have their own DestinE permission checks. Follow the [account guide](../setup/accounts.md) for the specific notebook.

Service status and access can change. The linked pages describe what providers documented; a listing does not prove that your account can use a collection. Check the [live Platform catalogue](https://platform.destine.eu/services/) and [Data Lake directory](https://data.destination-earth.eu/services)
